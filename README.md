# 🚀 Antigravity DeepSeek V4 AI Studio

Uma réplica de alta performance do **Antigravity IDE** alimentada pelo motor **DeepSeek V4** (com suporte a DeepSeek-R1 e DeepSeek-V3), subagentes autônomos em background, conexão direta com a API do GitHub e histórico de conversas preservado.

## 🔗 Acesse a Aplicação Online (Web App)
👉 **[Clique aqui para abrir o App na Web](https://roxamarcio21-a11y.github.io/antigravity-deepseek-v4/)** *(como no Lovable / Bolt!)*

---

## ✨ Recursos

- 🎨 **Interface Antigravity Obsidian Dark**: Layout responsivo com 3 painéis (Sidebar, Chat central com raciocínio expansível e Painel lateral de Artefatos).
- 🧠 **Motor DeepSeek-V4 & R1 Reasoning**: Raciocínio de cadeia ampla mostrando como a IA pensou antes de gerar o código.
- 🤖 **Sistema de Subagentes**: Invoque e acompanhe subagentes em segundo plano diretamente pela barra lateral.
- 🐙 **Integração com GitHub**: Conecte seu token do GitHub para consultar seus repositórios reais no chat.
- 🚀 **Hospedagem 100% Automática**: Funciona direto no GitHub Pages sem necessidade de Node.js local.
